How it stays fresh

GitHub Actions checks publisher RSS feeds hourly, even when the app is closed. The app checks the deployed edition when opened, every five minutes while visible, and when you tap “Check update”. That button checks the published edition; it does not run the GitHub updater.

Refreshes depend on GitHub Actions and publisher availability. Source warnings and timestamps show when something needs attention. Last loaded articles and saved picks are available offline after the first visit.
