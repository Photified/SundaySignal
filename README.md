# Sunday Signal

A clean, installable NFL expert picks reading room for GitHub Pages.

**Start with [START-HERE.md](START-HERE.md)** for the exact upload and automatic update setup.

Features: hourly publisher feeds through GitHub Actions, analyst attribution, explicit source selections, spread / moneyline / totals / props filters, search, saved articles, offline access, source health, standard icons and dedicated maskable icons. No paid API key or JavaScript framework required.
